# 🛍️ Django E-Commerce Website

A full-featured eCommerce web application built with Django.

---

## 🚀 Features

- 🛒 **Product Management**
  - Browse products by category, brand, or search
  - Admin panel to add, edit, or delete products

- 💳 **Shopping Cart & Checkout**
  - Add, remove, or update items in the cart
  - Calculate subtotal
  - Checkout

- 📦 **Order Management**
  - Order tracking and status updates

- 📱 **Responsive Design**
  - Fully responsive for mobile, tablet, and desktop

- ⚙️ **Admin Dashboard**
  - Manage products, users, and orders
  - Analytics overview and reports

---

## 🧰 Tech Stack

| Layer | Technology |
|--------|-------------|
| **Backend** | Django, Python |
| **Frontend** | HTML5, CSS3, JavaScript, Bootstrap 5 |
| **Database** | SQLite |
